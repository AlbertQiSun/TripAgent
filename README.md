# TripAgent

An intelligent, ReAct-based AI travel agent that dynamically plans itineraries, researches the internet, and maps out locations in a vibrant interactive UI.

## Features (Planned)
- **ReAct Agent Logic**: Transparent thought process showing reasoning, tool use, and actions.
- **Google Search Integration**: Live web research for real-time recommendations and reviews.
- **Interactive Mapping**: Google Maps integration to visualize itineraries.
- **Premium UI**: Dark mode, glassmorphism, dynamic animations.
